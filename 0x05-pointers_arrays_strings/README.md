# 0x05 - pointers_arrays_strings

this project introduce pointers, arrays, and strings

## Topic covered

what are pointer and how to use them
what are arrays and how to use them
how to use strings and manipulate them
scope of variables

## Tasks
0-reset_to_98.c - Function that takes pointer to an int as parameter and update is value it point 98
1-swap.c - Function that swap value of two integer
2-strlen.c - Function that return the length of string
3-puts.c - Function that print a string
4-print_rev.c - Function that print a string in reverse
5-rev_string.c - Function that reverse a string
6-put2.c - Function that print every other character of a string
7-puts_half.c - write function that print half of a string
8-print_array.c - Function that print n elenent of an array of integer
9-stripy.c - Function that copie a string from src to dest
10-atoi.c - Function that convert a string to an integer
101-keygen.c -Program that generate random valid password

### All file Compile using
gcc -Wall -Werror -Wextra -pedantic -std=gnu89
