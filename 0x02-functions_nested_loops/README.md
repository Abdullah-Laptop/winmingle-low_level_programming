# 0x02. C - Functions, nested loops
This project introduce function, nested loop and header file in C

## Topics covered

What are nested loops and how to use them
What is a function and how do you use functions
What is the difference between a declaration and a definition of a function
What is a prototype
Scope of variables
What are the gcc flags -Wall -Werror -pedantic -Wextra -std=gnu89
What are header files and how to to use them with #include

## Tasks 
### Mandatory

0-putchar - program the print _putchar
1-alphabet.c - function that print lowercase alphabet
2-print_alphabet_x10.c - funtion that print alphabet 10 times
3-islower.c - function that check lowercase character
4-isalpha.c - Function that check for alphabetic character
5-sign.c -Function that print sign of a number
6-abs.c - Function that compute absolute value
7-print_last_digit.c - Function that print last digit 
8-24_hours.c - Function that print munite of a day
9-times_table.c - Function that print 9 times table
10-add.c - Function that adds two interger
11-print_to_98.c - Function that print from n to 98

### Advanced

100-times_table.c - Function that print n time table
101-natural.c - Sum of multiples of 3 or 5 below 1024
102-fibonacci.c - print first 50 fibonacci numbers
103-fibonacci.c - Sum of even fibonacci terms below 4,000,000
104-fibonacci.c - first 98 fibonacci numbers (with overflow)

## Compilation

compile all file using:
gcc -Wall -Werror -Wextra -pedantic -std=gnu89

## header file
main.h - contains prototype of all function
