# C

This project introduces C programining language

## Topics covered

Write simple C programs
Compile and assemble C source file
Understand how executable was created
Follow clean C coding standards

## Task

### mandatory

'0-preprocessor' - write script that run a C through the preprocessor
'1-compiler' - Write a script that compiles a C file but does not link
'2-assember' - Write a script that generates the assembly code of a C code
'3-name' - Write a script that compiles a C file and creates an executable named cisfun
'4-puts.c' - Write a C program using puts
'5-printf.c' Write a C program using printf
'6-size.c' - Write a C program that prints the size of various types on your machine

### Advanced

'100' - write a script that generates the assembly code (Intel syntax) of a C code and saves to an output file
'101' - Write a C program that print in standard error

## compilation 

All file compiled with
'gcc -Wall -Werror -Wextra -pedantic -std=gnu89'
