# 0x01-varibles if, else, while

This project cover:
Arithemetic operators
Logistic boolean operators
Relational operators
if and if....else statements
while loops
ASCII character set
comments and variable declaration
printing variable values using printf

## Task
0-positive_or_negative.c - Random number check
1-last_digit.c -Extract last digit
2-print_alphabet.c - print lowercase using putchar
3-print_alphabets.c - print lowercase then uppercase
4-print_alphabt.c - print lowercase except 'q' and 'e'
5-print_numbers.c - print single digit of number base
6-print_numberz.c - print numbers 0-9 using only int variables
7-print_tebahpla.c - print the lowercase in reverse order
8-print_base16.c - print all the number of base 16 in lowercase
9-print_comb.c - Print all possible combinations of single-digit numbers separated by commas and spaces
100-print_comb3.c - Print all possible different combinations of two digits
101/print_comb4.c - Print all possible different combinations of three digits
102 print comb5.c - Print all possible combinations of two two-digit numbers

### Compilation

All file should be compile using:
'gcc -Wall -Werror -Wextra -pedantic -std=gnu89'
